Install Fantasy Athlete PvP on Android

On iPhone, iPad, Mac or PC? You don't need to install anything: play in your browser.

The Android app isn't in an app store, so you install the file yourself. It takes about two minutes. Needs Android 7.0 or newer.

2. Install

  1. Open the downloaded .apk (from your notifications or the Downloads app).
  2. If Android says it blocks installs from this source, tap Settings and allow it for your browser or file manager, then go back.
  3. Tap Install. If Play Protect asks, choose to install anyway: this is a sideloaded build, not a Play Store one.
  4. Updates install over the old version and keep your data, as long as they are signed with the same key (every release is).

3. Check the download (optional)

Every release lists a SHA-256 checksum. If Android says the package "can't be parsed" or is "invalid", the download is usually incomplete: compute the checksum of your file (sha256sum file.apk, or any checksum app) and compare it with the one below. If they differ, download again.

If something goes wrong

"App not installed"

You may have an older build signed with a different key. Uninstall it first (this removes its local data), then install again.

"There was a problem parsing the package"

The download is incomplete or damaged. Check the checksum above and download again.

Can't find the file

Look in the Downloads app, or in your browser's download list.

Still stuck?

Open an issue on GitHub and say your Android version and what the message says.
