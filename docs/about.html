About Fantasy Athlete PvP

Fantasy Athlete PvP is an Android app. Download the APK, install it, and update in place.

Privacy

The game stores your username, club name, a hash of your password, your game data and your matches on its server. Your IP address is used for rate limiting. Traffic passes through Cloudflare, and the app reads its server address from GitHub, so those services can see normal connection details. There are no ads and no payments. This is an early beta: the server runs on a single computer, so it can go offline and data could be lost. Don't reuse a password from another service.

Help and feedback

Found a problem or have an idea? Open an issue on GitHub. Every release and its notes are on the releases page.

How releases are made

Each release is built, checked against the app's signing key and published to GitHub together with a SHA-256 checksum. This site and the app's update check read the same releases.json.
