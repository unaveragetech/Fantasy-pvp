# Fantasy Athlete PvP 0.9.0 (first public beta)

- Collect athletes from 3D mystery lockers and build clubs from 5,000 unique athletes.
- Play 27 game types, with several venues for each.
- Ranked games against real managers are the only official stats. Casual and bot games are tracked separately.
- See accuracy and stats for each player on each team.
- Watch replays in 3D or 2D, and check the odds and roll behind each contest.
- The app finds the game server automatically if its address changes.

Known limits: this is an early beta, and the server runs on one computer, so it can go offline. You may need to sign in again if the server address changes. No real money is involved anywhere in the game.
